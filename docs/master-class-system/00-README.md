## 🚀 Quick Start (5 Minutes)

### 1. Install Cagent
```bash
brew install docker-cagent
```

### 2. Set API Keys
```bash
cat > .env << EOF
ANTHROPIC_API_KEY=your_key
OPENAI_API_KEY=your_key
GITHUB_TOKEN=your_token
EOF
```

### 3. Activate in VS Code Copilot Chat
```
@copilot I'm activating the SYNAPSE WEAVER MASTER CLASS PROMPT SYSTEM v1.0.
Ready for directives.
```

### 4. Execute First Feature
```
@copilot /implement-feature "Command Deck UI" --priority high
```
